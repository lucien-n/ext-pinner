# Pinner

Pinner is a simple chrome extension to persist pinned tabs between sessions.

It only requires storage and tabs permissions.

Create a collection from currently pinned tabs.
Add, remove and reorganize urls in a collection.
Mark a collection as autoloaded so it automatically opens its urls as pinned tabs.

- shadcn-svelte
